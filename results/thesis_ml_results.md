- **label=1**: Resume and job description are from the **same occupational category** (e.g., a Python Developer resume paired with a Python Developer JD)
- **label=0**: Resume and job description are from **different occupational categories** (e.g., a Cybersecurity Analyst resume paired with a Marketing Manager JD)

All occupation profiles were constructed from publicly available occupational taxonomies:
- O*NET-SOC (US Department of Labor, public domain)
- ESCO occupation descriptions (European Commission, CC BY 4.0)
- Expanded from existing project sample data (20 original pairs)

## G. Honest Interpretation & Limitations

> [!WARNING]
> The following limitations must be acknowledged in the thesis for academic integrity.

### Why Scores Are High

The near-perfect baseline (F1=0.9565) and perfect trained model (F1=1.0) on the held-out test set occur because:

1. **The dataset is category-separable**: Matched pairs (label=1) are same-category resume-JD pairs; non-matched pairs (label=0) are different-category pairs. This creates a large vocabulary separation signal.

2. **TF-IDF cosine statistics confirm easy separation**:
   - Matched pairs cosine similarity: mean = **0.3529** (σ = 0.2121)
   - Non-matched pairs cosine similarity: mean = **0.0344** (σ = 0.0310)
   - Separation: **0.3185** — a large, discriminative gap

3. **n=18 test set is small**: On 18 samples, missing even one prediction changes F1 by ~0.05.

### What This Does and Does NOT Prove

✅ **Does prove**: The JobMatch AI matching signal (text similarity + token overlap) is effective at distinguishing between-domain mismatches from same-domain matches. This is the core use case of the system.

❌ **Does NOT prove**: That the system performs at 91%+ F1 on real-world hard cases (e.g., a Java developer applying to a Python role — both software engineering but mismatched skills). Real-world evaluation would require within-category hard negatives.

### Recommended Thesis Language

*"The hybrid matching engine, evaluated on a 118-pair labeled dataset of occupation-matched and occupation-mismatched resume-job pairs, achieves a 5-fold cross-validated F1-Score of 0.91 (± 0.02) using a Random Forest classifier trained on TF-IDF similarity and token overlap features. The baseline TF-IDF cosine system achieves F1=0.96 on the held-out test set, indicating strong separability between matched and mismatched occupation domains. These results validate the system's core matching signal but should be interpreted with the caveat that the evaluation dataset uses occupation-category-level matching; within-category hard-negative evaluation (e.g., mismatched skill levels within the same domain) would be required for a more stringent assessment of real-world discrimination ability."*
